# Changelog

## 0.1.2 — 2026-11-22

- Put configured streaming websites and the optional FMHY directory first in Watch Now for movies and TV episodes, with explicit unverified browser destination labels.
- Separate official watch providers and add an option to hide paid rentals and purchases while retaining subscription listings.
- Add website editing, favorites, and removal while preserving existing bookmarks, settings, watchlist storage, and TMDB credentials.
- Add LiveContainer source installation and update instructions, a correctly encoded source deep link, manual fallback, copy-source and release links.
- Extend source metadata compatibility for LiveContainer while retaining the official AltSource fields and verified IPA checks.

Early development release. LiveContainer installation and data-container retention require physical-device testing.

## 0.1.1 — 2026-10-26

- Add an in-app, step-by-step TMDB setup tutorial with the exact application form values, copy buttons, token guidance, and iPhone troubleshooting.
- Configure the public StreamHub IPA source for SideStore/AltStore and in-app update checks.
- Publish a verified unsigned IPA, SHA-256 checksum, release notes, and automatically generated source metadata.
- Make release retries preserve already-published IPA assets and retain build artifacts if source hosting fails.

Early development release. Physical iPhone 17, SideStore, and LiveContainer compatibility testing remains pending; signing or a compatible import tool is required.

## 0.1.0 — development artifact, 2026-10-26

- Add the native five-tab discovery application with TMDB metadata, title search, movie and television details, seasons, episodes, and local watchlist.
- Add a persistent web browser, user-configured authorized native playback, playback history, and title-level regional provider information.
- Add optional FMHY website discovery with caching and explicit unverified labels.
- Add validated update source handling, a fullscreen update notice, and installation tutorials.
- Add Swift package tests, iOS integration tests, unsigned IPA workflows, original branding, and documentation.

No stable release or device compatibility certification is implied by this entry.
